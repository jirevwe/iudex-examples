# Claude Development Context: Iudex Examples

## Project Purpose

This is the **examples repository** for the [Iudex API Testing Framework](../iudex).

It demonstrates how to integrate Iudex's dashboard into real-world applications using Express, Fastify, and standalone HTTP servers.

## Relationship to Main Iudex Repo

**Location:** `/Users/rtukpe/Documents/dev/gotech/iudex-examples`
**Main Repo:** `/Users/rtukpe/Documents/dev/gotech/iudex`

This repo uses Iudex as a **local file dependency**:
```json
{
  "dependencies": {
    "iudex": "file:../iudex"
  }
}
```

### Development Workflow

1. **Make changes in `../iudex`** (main library)
2. **Changes are automatically available** in this repo (via symlink)
3. **Test here** to verify integration works
4. **No manual updates needed** - npm link handles it

### When to Update

- After modifying dashboard server code in `iudex/server/`
- After changing dashboard templates in `iudex/templates/dashboard/`
- After updating reporters in `iudex/reporters/`

Simply run the examples - they'll use the latest local code.

## Key Points for Claude

### Import Paths

All examples import from the **installed package**, not relative paths:

```javascript
// ✅ Correct
import { createExpressDashboard } from 'iudex/server/express';

// ❌ Wrong (old examples path)
import { createExpressDashboard } from '../../server/index.js';
```

### Test Data Location

Examples point to Iudex's test results:

```javascript
const iudexResultsDir = path.join(__dirname, '..', '..', 'iudex', '.iudex', 'results');
```

This allows examples to use real test data from the main library.

### Running Examples

```bash
# Using npm
npm run express
npm run fastify
npm run standalone

# Using mise (recommended)
mise run express
mise run fastify
mise run standalone
```

### Testing Examples

```bash
# API tests
mise run test:api

# Browser tests (requires Playwright)
mise run test:browser
```

## Common Tasks

### Add New Example

1. Create new file in `dashboard/`
2. Import from `iudex/server/*`
3. Add script to `package.json` and `.mise.toml`
4. Update README.md

### Update Import Paths

When Iudex's export structure changes:
1. Update all `import` statements in `dashboard/*.js`
2. Test with `mise run test:api`

### Debug Integration Issues

1. Verify Iudex is linked: `ls -la node_modules/iudex`
2. Check import paths match Iudex's `package.json` exports
3. Ensure test data exists: `ls ../iudex/.iudex/results/`

## Dependencies

**Runtime:**
- `iudex` - Main library (file: dependency)
- `express` - Express framework
- `fastify` - Fastify framework

**Dev:**
- `@playwright/test` - Browser testing
- `playwright` - Browser automation

## Integration Points

### With Main Iudex Repo

- Reads test results from `../iudex/.iudex/results/`
- Imports server handlers from `iudex/server/*`
- Uses dashboard templates via imported handlers

### With Test Data

Examples expect test data in:
```
../iudex/.iudex/results/
├── run-YYYY-MM-DDTHH-MM-SS.json
├── latest.json
└── ...
```

Run tests in main repo first: `cd ../iudex && npm run test:integration`

## Keeping Examples Updated

When Iudex changes:

1. **API Changes:** Update import statements if exports change
2. **Config Changes:** Update example configurations
3. **New Features:** Add examples demonstrating new features
4. **Breaking Changes:** Update all examples and document in README

## Quality Checks

Before committing:

```bash
# Ensure dependencies are installed
mise run install

# Test all examples start without errors
mise run express &    # Should start on 3000
mise run fastify &    # Should start on 3001
mise run standalone & # Should start on 8080

# Run tests
mise run test:api
mise run test:browser

# Clean up
pkill -f "express-server"
pkill -f "fastify-server"
pkill -f "standalone-server"
```
