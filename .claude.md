# Claude Development Context: Iudex Examples

## Project Purpose

This is the **examples repository** for the [Iudex API Testing Framework](../iudex).

It demonstrates how to integrate Iudex's dashboard into real-world applications using Express, Fastify, and standalone HTTP servers, plus various test examples.

## Relationship to Main Iudex Repo

**Location:** `/Users/rtukpe/Documents/dev/gotech/iudex-examples`
**Main Repo:** `/Users/rtukpe/Documents/dev/gotech/iudex`

Each example uses Iudex as a **local file dependency**:
```json
{
  "dependencies": {
    "iudex": "file:../../iudex"
  }
}
```

### Development Workflow

1. **Make changes in `../iudex`** (main library)
2. **Changes are automatically available** in examples (via symlink)
3. **Test here** to verify integration works
4. **No manual updates needed** - npm handles it

### When to Update

- After modifying dashboard server code in `iudex/server/`
- After changing dashboard templates in `iudex/templates/dashboard/`
- After updating reporters in `iudex/reporters/`

Simply run the examples - they'll use the latest local code.

## Key Points for Claude

### No Top-Level Dependencies

There is **NO** top-level `package.json`. Each example folder is self-contained with its own dependencies.

### Import Paths

All examples import from the **installed package**, not relative paths:

```javascript
// ✅ Correct
import { createExpressDashboard } from 'iudex/server/express';

// ❌ Wrong
import { createExpressDashboard } from '../../server/index.js';
```

### Test Data Location

Dashboard examples point to Iudex's test results:

```javascript
const iudexResultsDir = path.join(__dirname, '..', '..', 'iudex', '.iudex', 'results');
```

This allows examples to use real test data from the main library.

### Running Examples

```bash
# Using mise (recommended)
mise run express       # Express server on port 3000
mise run fastify       # Fastify server on port 3001
mise run standalone    # HTTP server on port 8080

# Run tests
mise run test:httpbin
mise run test:simple
mise run test:failures
mise run test:governance
mise run test:all      # Run all tests

# Install dependencies for all examples
mise run install

# Clean all examples
mise run clean
```

### Running Individual Examples

```bash
# Express example
cd express-dashboard
npm install
npm start              # or npm run dev

# Fastify example
cd fastify-dashboard
npm install
npm start              # or npm run dev

# Run a specific test
cd httpbin-tests
npm install
npm test
```

## Common Tasks

### Add New Dashboard Example

1. Create new folder (e.g., `koa-dashboard/`)
2. Create `package.json` with iudex dependency
3. Create server file importing from `iudex/server/*`
4. Add task to `.mise.toml`
5. Update this `.claude.md` and `README.md`

### Add New Test Example

1. Create new folder (e.g., `my-api-tests/`)
2. Create `package.json` with iudex dependency
3. Create test file using Iudex API
4. Add task to `.mise.toml`
5. Update this `.claude.md` and `README.md`

### Update Import Paths

When Iudex's export structure changes:
1. Update all `import` statements in example server files
2. Test with `mise run express` (or relevant example)

### Debug Integration Issues

1. Verify Iudex is linked: `ls -la */node_modules/iudex`
2. Check import paths match Iudex's `package.json` exports
3. Ensure test data exists: `ls ../iudex/.iudex/results/`
4. Reinstall dependencies: `cd <example-dir> && npm install`

## Dependencies

Each example has its own dependencies:

**Dashboard Examples:**
- `iudex` - Main library (file: dependency)
- `express` - Express framework (express-dashboard only)
- `fastify` - Fastify framework (fastify-dashboard only)

**Test Examples:**
- `iudex` - Main library (file: dependency)

## Integration Points

### With Main Iudex Repo

- Reads test results from `../iudex/.iudex/results/`
- Imports server handlers from `iudex/server/*`
- Uses dashboard templates via imported handlers

### With Test Data

Examples expect test data in:
```
../iudex/.iudex/results/
├── run-YYYY-MM-DDTHH-MM-SS.json
├── latest.json
└── ...
```

Generate test data: `cd ../iudex && npm run test:integration`

## Keeping Examples Updated

When Iudex changes:

1. **API Changes:** Update import statements if exports change
2. **Config Changes:** Update example configurations
3. **New Features:** Add examples demonstrating new features
4. **Breaking Changes:** Update all examples and document in README
